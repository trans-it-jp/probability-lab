# 確率実験ラボ

さいころを指定した回数だけ振り、**理論上の確率**と**実際の結果**を、割合と回数の両方で並べて比べる試作。

## できること

1. 条件を決める（試行回数・注目する目・さいころの偏り・乱数の種）
2. 予想する（書かないと実験に進めない）
3. 実験する
4. 比べる（割合と回数を併記、相対度数の推移を図示）
5. 自分の言葉で説明する

## 動かす

`index.html` をブラウザで開くだけ。ビルドもインストールも要らない。

```
node tests/run.js
```

計算の検証はこれで走る。外部パッケージは使わない。画面が要る確認（図と数値の一致・表示倍率・キーボード操作・初見利用）は `tests/index.html` をブラウザで開く。

## 作り

| 場所 | 役割 |
|---|---|
| `index.html` | 画面 |
| `css/site.css` | 見た目。小さな画面と表示倍率の変更に耐えることを優先 |
| `js/core/seeded-random.js` | 種を指定できる疑似乱数（0004 から流用、MIT。`NOTICE` 参照） |
| `js/probability/experiment.js` | 実験の計算。DOM を使わないので Node で検証できる |
| `js/app.js` | 画面の配線と SVG の描画 |
| `tests/` | 検証 |

**外部ライブラリは読み込んでいない。** 図は素の SVG で描いている。実験の計算はすべてブラウザの中で完結し、入力も結果も外部には送らない。
